This roundup looks at how the rise of AI-generated code is reshaping the business of software testing. As code gets written faster than ever, the need to confirm that applications actually behave as intended is becoming a market opportunity in its own right.

## Polish Startup e2e Raises $8M to Bet on Verifying AI-Written Code
e2e, a Polish company formerly known as TesterArmy, has secured an $8M seed round to grow an open testing framework that anyone can use for free, while monetizing infrastructure and enterprise-focused services. The startup's premise is that AI speeds up code production but does nothing to remove the need to check that software works correctly. For testers, it's a signal that verification is increasingly seen as the bottleneck in AI-assisted development, and that new open tooling aimed at this gap is attracting serious investment.
